# GreatPLLTrainer

To run, just clone the repo, install Pygame if you haven't (`pip install pygame`), and do `python main.py`.  From there, just press space to cycle through the cases in random order.

You can customize the cases used in the `cases.txt` file. For example, if you're practicing distinguishing specific cases, you can comment out the other cases.

This tool specifically gives you control over whether to include or not each angle of every case. Instead of most tools letting you include Aa perm not, you can customize whether each of the 4 angles you can see Aa perm from show up or not.
